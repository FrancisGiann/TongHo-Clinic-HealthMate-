# HealthMate+ system QA — 2026-10-13

## Result

No application defect was confirmed, so this QA pass made no source-code changes. Browser workflows used the actual Vite client, Express API, and a disposable local PostgreSQL database. All records used fictional development accounts, one seeded fictional student, and a QA-only inventory item. No remote database or external email delivery was used. After the browser QA, the configured Gemini adapter received one separate, synthetic encounter request and returned a non-empty summary.

## Disposable runtime setup

The QA database was an ephemeral `postgres:16` container with no mounted data volume. To repeat the workflow locally, use an explicit local connection string before running any database command; do not use a configured remote database URL.

```sh
docker run --rm --name healthmate-system-qa \
  -e POSTGRES_USER=healthmate_qa \
  -e POSTGRES_PASSWORD=qa-local-only \
  -e POSTGRES_DB=healthmate_qa \
  -p 127.0.0.1:55432:5432 postgres:16
```

In another terminal, with the repository’s dependencies installed:

```sh
export DATABASE_URL='postgres://healthmate_qa:qa-local-only@127.0.0.1:55432/healthmate_qa'
export DB_SSL=false NODE_ENV=development REQUIRE_LOGIN_OTP=false
export SEED_DEV_ROLE_ACCOUNTS=true SEED_DEMO_DATA=false
export BOOTSTRAP_ADMIN_EMAIL='' BOOTSTRAP_ADMIN_PASSWORD=''
export SMTP_HOST='' SMTP_USER='' SMTP_PASS=''
export GEMINI_DEMO_MODE=false GEMINI_API_KEY=''
export AI_SUMMARY_PROVIDER='' AI_SUMMARY_ENDPOINT='' AI_SUMMARY_API_KEY=''

npm run db:migrate
npm run db:preflight-dev-accounts
npm run db:seed-dev-accounts
```

Run the API and client in separate terminals using the same explicit environment:

```sh
PORT=4174 npm run server
```

```sh
VITE_API_BASE_URL=http://127.0.0.1:4174 \
  ./node_modules/.bin/vite --host 127.0.0.1 --port 5173
```

Open `http://127.0.0.1:5173`. Development CORS explicitly permits localhost, 127.0.0.1, and ::1 on Vite ports 5173–5179; no additional CORS setting is needed for this setup. Keep the bootstrap admin variables blank so a local configured admin is never copied into the disposable database. An empty AI provider with no endpoint/key uses the built-in local template behavior.

Use only the repository’s fictional development accounts and fixture student. Stop the container to discard all QA rows; the actual QA container was stopped and removed after verification.
